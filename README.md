# Personal Portfolio

A personal software engineering portfolio built with Next.js, React, TypeScript, Tailwind CSS, and Supabase.

The portfolio highlights selected projects, professional experience, technical skills, education, and contact information in a clean and responsive interface.

## Highlights

- Responsive design for desktop, tablet, and mobile
- Light and dark themes
- Featured project showcase
- Individual project case studies
- Experience and education sections
- Technical skills and capabilities
- Resume viewer and download
- Contact form
- GitHub and live project links

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Vercel

## Local Development

Clone the repository and install dependencies:

```bash
npm install
```

Create a local environment file from the example:

```bash
cp .env.example .env.local
```

Add the required environment variables, then start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## Production Build

```bash
npm run build
```

Run linting with:

```bash
npm run lint
```

## Environment Variables

The required environment variable names are documented in `.env.example`.

Keep real credentials in `.env.local` or in your deployment platform's environment settings.

Do not commit `.env.local`.

## Deployment

The portfolio can be deployed on Vercel with Supabase used for backend services and data storage.
